# astarte-sdk-csharp

C# bindings for the [Astarte Device SDK](https://github.com/astarte-platform/astarte-device-sdk-rust), generated by [BoltFFI](https://www.boltffi.dev/docs/getting-started) (v0.25+).

---

## Project layout

```
astarte-sdk-csharp/
├── AstarteSdk.sln
├── AstarteSdk/                  ← library (net8.0) — BoltFFI-generated sources + post-gen fix
│   ├── AstarteDeviceSdkBindings.cs   ← WireReader/Writer, vtable bridge, P/Invoke
│   ├── AstarteConfig.cs
│   ├── AstarteVal.cs                 ← abstract record with 13 sealed record variants
│   ├── ObjectEntry.cs
│   ├── SdkError.cs                   ← error record hierarchy + SdkErrorException
│   └── AstarteDevice.cs              ← generated + post-gen fix (public constructor)
├── AstarteSdk.Tests/            ← xUnit tests (no native library needed)
│   ├── AstarteValTests.cs
│   ├── AstarteConfigTests.cs
│   ├── ObjectEntryTests.cs
│   └── WireCodecTests.cs            ← encode/decode round-trips for all AstarteVal variants
└── AstarteSdkExample/           ← console demo app
    └── Program.cs
```

## Generating the C# bindings

The sources in `AstarteSdk/` are produced by BoltFFI and then copied here with a post-generation fix applied. To regenerate from scratch:

```sh
# From the repo root
boltffi pack csharp --release
```

Output lands in `dist/csharp/`:
- `src/*.cs` — C# source files (namespace `AstarteDeviceSdkBindings`)
- `runtimes/linux-x64/native/libastarte_device_sdk_bindings.so` — compiled native library

Copy the generated sources into the library project:

```sh
cp dist/csharp/src/*.cs astarte-sdk-csharp/AstarteSdk/
```

Then re-apply the post-generation fix described below.

## Post-generation fix

The C# generator does not emit the `AstarteDevice` constructor. After each `boltffi pack csharp`, apply these two edits to the **copied** files (not the `dist/` originals):

**1. `AstarteDeviceSdkBindings.cs` — add inside `NativeMethods`, before `AstarteDeviceFree`:**

```csharp
[DllImport(LibName, EntryPoint = "boltffi_astarte_device_new")]
internal static extern IntPtr AstarteDeviceNew(byte[] config, UIntPtr configLen, byte[] interfacesDir, UIntPtr interfacesDirLen);
```

**2. `AstarteDevice.cs` — add `using System.Runtime.InteropServices;` at the top and insert after the private constructor:**

```csharp
public AstarteDevice(AstarteConfig config, string interfacesDir)
    : this(CreateHandle(config, interfacesDir)) { }

private static IntPtr CreateHandle(AstarteConfig config, string interfacesDir)
{
    using var configWire = new WireWriter(config.WireEncodedSize());
    config.WireEncodeTo(configWire);
    byte[] configBytes = configWire.ToArray();
    byte[] dirBytes = Encoding.UTF8.GetBytes(interfacesDir);
    IntPtr handle = NativeMethods.AstarteDeviceNew(
        configBytes, (UIntPtr)configBytes.Length,
        dirBytes, (UIntPtr)dirBytes.Length);
    if (handle == IntPtr.Zero)
        throw new SdkErrorException(new SdkError.Config("Failed to create AstarteDevice"));
    return handle;
}
```

## Run the example app

The example requires the native shared library and a reachable Astarte broker.

**1. Copy the native library:**

```sh
cp dist/csharp/runtimes/linux-x64/native/libastarte_device_sdk_bindings.so \
   astarte-sdk-csharp/AstarteSdkExample/
```

**2. Edit credentials** in `AstarteSdkExample/Program.cs` to match your Astarte realm and device.

**3. Run:**

```sh
dotnet run --project AstarteSdkExample/
```

The runtime finds `libastarte_device_sdk_bindings.so` next to the executable. Alternatively, set `LD_LIBRARY_PATH` to its directory.

## API overview

```csharp
using AstarteDeviceSdkBindings;

// Configure
var config = new AstarteConfig(
    Realm: "myrealm",
    DeviceId: "...",
    CredentialsSecret: "...",
    PairingUrl: "http://api.astarte.example/pairing",
    IgnoreSsl: false);

// Connect and listen
using var device = new AstarteDevice(config, "path/to/interfaces");
device.StartListening(new MyEventListener()); // blocks until disconnected

// Send data
device.Send("com.example.Interface", "/path", new AstarteVal.Integer(42));
device.Send("com.example.Interface", "/path", new AstarteVal.Double(3.14));
device.Send("com.example.Interface", "/path", new AstarteVal.IString("hello"));

// Disconnect
device.Disconenct();
```

Implement `EventListener` to receive events:

```csharp
sealed class MyEventListener : EventListener
{
    public void OnConnected() { }
    public void OnDisconnected() { }
    public void OnDataReceived(string iface, string path, AstarteVal data) { }
    public void OnObjectReceived(string iface, string path, ObjectEntry[] entries) { }
    public void OnPropertyReceived(string iface, string path, AstarteVal data) { }
    public void OnPropertyUnset(string iface, string path) { }
}
```

### AstarteVal variants

| Variant | C# type | Tag |
|---|---|---|
| `AstarteVal.Double` | `double` | 0 |
| `AstarteVal.Integer` | `int` | 1 |
| `AstarteVal.Boolean` | `bool` | 2 |
| `AstarteVal.LongInteger` | `long` | 3 |
| `AstarteVal.IString` | `string` | 4 |
| `AstarteVal.BinaryBlob` | `byte[]` | 5 |
| `AstarteVal.DateTime` | `long` (ms since epoch) | 6 |
| `AstarteVal.DoubleArray` | `double[]` | 7 |
| `AstarteVal.IntegerArray` | `int[]` | 8 |
| `AstarteVal.BooleanArray` | `bool[]` | 9 |
| `AstarteVal.LongIntegerArray` | `long[]` | 10 |
| `AstarteVal.StringArray` | `string[]` | 11 |
| `AstarteVal.DateTimeArray` | `long[]` | 12 |

> **Note:** Variants that hold arrays (`BinaryBlob`, `DoubleArray`, etc.) are C# `record` types. C# records use reference equality for array fields — two instances with the same content are not record-equal. Compare `.Value` directly when needed.
