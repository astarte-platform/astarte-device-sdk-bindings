# astarte-sdk-java

Java bindings for the [Astarte Device SDK](https://github.com/astarte-platform/astarte-device-sdk-rust), generated by [BoltFFI](https://www.boltffi.dev/docs/getting-started).

## Generating the Java bindings

The sources under `app/src/main/java/org/astarte/device/sdk/bindings/` are produced by BoltFFI. To regenerate from scratch:

```sh
# From the repo root — JAVA_HOME must be set
export JAVA_HOME="/usr/lib/jvm/java-8-openjdk-amd64"
boltffi pack java
```

Output lands in `dist/java/`:
- `libastarte_device_sdk_bindings.so` — core Rust shared library
- `libastarte_device_sdk_bindings_jni.so` — JNI wrapper
- `org/astarte/device/sdk/bindings/` — generated Java sources

Copy the sources into the app module:

```sh
cp -r dist/java/org astarte-sdk-java/app/src/main/java/
```

Then re-apply the post-generation fix described below.

---

## Post-generation fix

BoltFFI generates `Double.compare`, `Double.hashCode`, `Boolean.hashCode`, and `Integer.hashCode` as static calls inside inner classes that shadow the `java.lang.*` types. After each `boltffi pack java`, apply these corrections in the **copied** `AstarteVal.java`:

```java
// AstarteVal.Double.hashCode() — qualify with java.lang.Double
result = 31 * result + java.lang.Double.hashCode(value);
return java.lang.Double.compare(this.value, other.value) == 0;

// AstarteVal.Boolean.hashCode() — qualify with java.lang.Boolean
result = 31 * result + java.lang.Boolean.hashCode(value);

// AstarteVal.Integer.hashCode() — qualify with java.lang.Integer
result = 31 * result + java.lang.Integer.hashCode(value);
```

```sh
gradle build

# Run unit tests (no native library required)

```

## Run the example app

The example requires both native shared libraries and a reachable Astarte broker.

**1. Copy the native libraries:**

```sh
cp dist/java/libastarte_device_sdk_bindings_jni.so \
   astarte-sdk-java/app/libs/native/

mkdir -p astarte-sdk-java/app/target/debug
cp dist/java/libastarte_device_sdk_bindings.so \
   astarte-sdk-java/app/target/debug/
```

**2. Edit credentials** in `app/src/main/java/org/example/app/App.java` to match your Astarte realm and device.

**3. Run:**

```sh
cd astarte-sdk-java
gradle run
```

The JVM is launched with `-Djava.library.path=libs/native` (set in `app/build.gradle`), so the JNI `.so` must be in `app/libs/native/`.

## API overview

```java
import org.astarte.device.sdk.bindings.*;

// Configure
AstarteConfig config = new AstarteConfig(
    "myrealm",
    "device-id",
    "credentials-secret",
    "http://api.astarte.example/pairing",
    false);

// Connect and listen
try (AstarteDevice device = new AstarteDevice(config, "path/to/interfaces")) {
    ExecutorService executor = Executors.newSingleThreadExecutor();
    executor.submit(() -> device.startListening(new MyEventListener()));

    // Send data
    device.send("com.example.Interface", "/path", new AstarteVal.Integer(42));
    device.send("com.example.Interface", "/path", new AstarteVal.Double(3.14));
    device.send("com.example.Interface", "/path", new AstarteVal.IString("hello"));

    device.disconenct();
}
```

Implement `EventListener` to receive events:

```java
class MyEventListener implements EventListener {
    public void onConnected() { }
    public void onDisconnected() { }
    public void onDataReceived(String iface, String path, AstarteVal data) { }
    public void onObjectReceived(String iface, String path, List<ObjectEntry> entries) { }
    public void onPropertyReceived(String iface, String path, AstarteVal data) { }
    public void onPropertyUnset(String iface, String path) { }
}
```

### AstarteVal variants

| Variant | Java type |
|---|---|
| `AstarteVal.Double` | `double` |
| `AstarteVal.Integer` | `int` |
| `AstarteVal.Boolean` | `boolean` |
| `AstarteVal.LongInteger` | `long` |
| `AstarteVal.IString` | `String` |
| `AstarteVal.BinaryBlob` | `byte[]` |
| `AstarteVal.DateTime` | `long` (ms since epoch) |
| `AstarteVal.DoubleArray` | `double[]` |
| `AstarteVal.IntegerArray` | `int[]` |
| `AstarteVal.BooleanArray` | `boolean[]` |
| `AstarteVal.LongIntegerArray` | `long[]` |
| `AstarteVal.StringArray` | `String[]` |
| `AstarteVal.DateTimeArray` | `long[]` |

## Notes

- The `disconenct()` method name is a typo inherited from the Rust FFI surface; it is preserved as-is to match the generated bindings exactly.
- Refer to the [BoltFFI documentation](https://www.boltffi.dev/docs/getting-started) for troubleshooting or advanced configuration.
